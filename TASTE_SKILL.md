# Mobile Taste Design System (Anti-Slop Guidelines)

This project adheres to the **Mobile Taste Design** principles to ensure an artisanal, premium fintech product experience (inspired by Linear, Apple Design Award winners, and modern Material 3 craft).

## Core Directives
1. **Solid Surfaces & Intentional Contrast**: All containers, sheets, and cards use solid, composited surfaces without muddy background bleed-through.
2. **Glanceable Financial Hierarchy**: Headline amounts are prominent, using bold tabular figures with elegant muted currency indicators.
3. **8dp Spatial Rhythm**: 4/8/12/16/20/24dp standard spacing for perfect breathing room across various screen sizes.
4. **Micro-Tactile Physics**: Interactive touch targets feel responsive with smooth bouncy springs and press states.
5. **Ergonomic Thumb Zone**: Primary actions (Add Expense FAB, primary dialog confirms) stay comfortably within the bottom third of the display.
